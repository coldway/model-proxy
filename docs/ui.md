# UI 管理面板

## 技术实现

管理面板采用**内嵌单文件 HTML** 方式实现（`src/api/ui.py`），无需 Node.js 或前端构建工具。整个 UI 作为 Python 三引号字符串内嵌，通过 FastAPI 的 `/ui` 端点直接返回。

- 前端框架：原生 HTML/CSS/JavaScript
- 主题：深色主题（Dark Theme）
- 响应式：支持桌面和移动端
- API 交互：使用 `fetch` 调用后端 REST API

## 功能模块

### 1. 使用量监控 (`#usage`)

实时展示各已启用模型的调用情况：
- 每日用量进度条（按 RPD 百分比着色：绿/黄/红）
- 当前分钟请求数
- 可用状态标识
- 每 30 秒自动刷新

### 2. 模型管理 (`#models`)

**厂商卡片网格**

- 展示所有 10 个厂商的卡片，从 catalog API 和 config API 合并数据
- 每张卡片显示：优先级徽章、厂商图标/名称、启用开关、已配置/已启用数量、API Key 状态
- 卡片右下角有 `?` 图标，点击弹出接入说明

**拖拽排序**

- 支持 HTML5 Drag and Drop API
- 拖拽卡片调整厂商优先级顺序
- 放下后自动调用 `POST /api/provider/reorder` 保存
- 优先级徽章实时更新

**厂商模型弹窗**

点击卡片打开模型管理弹窗，包含三个区域：

1. **已启用模型列表**
   - 显示当前厂商下所有 `enabled: true` 的模型
   - 支持拖拽排序调整模型优先级
   - 提供启用/禁用开关和停用按钮

2. **搜索 & 拉取模型**
   - 输入框支持 300ms 防抖搜索
   - 搜索 `providers_catalog.yaml` 目录中当前厂商的模型
   - 「拉取厂商全部」按钮调用 `GET /api/provider/{name}/models` 获取远程模型
   - 拉取的远程模型可添加到目录或直接启用

3. **手动添加自定义模型**
   - 折叠面板（`<details>` 元素）
   - 输入模型 ID、优先级、RPD/RPM 后直接添加到配置

### 3. 问答聊天 (`#chat`)

内置聊天界面：
- 模型选择器支持 `auto` 或具体模型
- 对话上下文持续传递（chatHistory 数组）
- 流式响应，实时显示输出
- 消息显示对应的模型名称和执行模式标签

**Cursor Agent CLI 模式选择器**

当选择 Cursor 相关模型时，聊天界面会自动显示模式选择器：

| 控件 | 说明 | 可选值 |
|------|------|--------|
| **模式按钮** | 选择 Cursor 执行模式 | `agent` (默认，全权限) / `plan` (规划模式，只读) / `ask` (问答模式，只读) |
| **Force 复选框** | 允许修改文件无需确认 | 仅 `agent` 模式有效，`plan`/`ask` 模式下此选项禁用 |
| **Sandbox 下拉框** | 控制沙箱执行环境 | `""` (默认) / `enabled` / `disabled` |

**模式标签显示**

AI 回复气泡下方会显示两类标签：
- **模型标签**（蓝色）：显示实际使用的模型名称，如 `🤖 composer-2.5`
- **模式标签**（彩色）：当使用非默认模式时显示
  - `📐 PLAN` — 紫色标签，规划模式
  - `💬 ASK` — 绿色标签，问答模式
  - `agent` 模式不显示标签（默认行为）

**可见性规则**

模式选择器的显示逻辑：
- 选择 **Cursor 相关模型**（如 `composer-2.5`）时显示
- 选择 **`auto` 自动模式**时也显示（因为 auto 可能路由到 Cursor 模型，用户可提前设置 mode）
- 选择**非 Cursor 模型**时隐藏（如 GPT、Claude 等不支持这些参数）

**参数生效规则**

- 当实际路由到 Cursor 模型时，`mode`/`force`/`sandbox` 参数会生效
- 当路由到其他厂商模型时，这些参数会被忽略，不影响正常使用

### 4. API Key 配置 (`#config`)

- 展示所有厂商的 API Key 配置状态
- 密码输入框，点击保存后调用 API
- 配置/未配置状态标识

## 交互细节

**Tab 切换保持**

使用 `location.hash` 记录当前 tab，刷新页面后自动恢复。URL 格式：`/ui#models`。

**弹窗管理**

- 所有弹窗使用 `modal-overlay` 遮罩层
- 点击遮罩层外部区域自动关闭
- 弹窗出现时带有缩放动画

**Toast 通知**

- 固定在右上角
- 支持 success/error/info 三种样式
- 3 秒后自动消失

## 厂商元数据

UI 中的 `providerMeta` JavaScript 对象维护各厂商的显示信息：

| 字段 | 说明 |
|------|------|
| name | 显示名称 |
| icon | 图标字符（单字母） |
| color | CSS 图标渐变色类名 |
| desc | 简短描述 |
| url | 官方网站链接 |
| guide | 接入说明文本（`\n` 分隔） |

## 样式变量

UI 使用 CSS 变量定义主题色：

| 变量 | 用途 |
|------|------|
| `--bg-primary` | 页面背景 `#0f172a` |
| `--bg-secondary` | 卡片背景 `#1e293b` |
| `--accent-blue` | 主色调 `#3b82f6` |
| `--accent-cyan` | 强调色 `#06b6d4` |
| `--accent-green` | 成功/可用 `#10b981` |
| `--accent-red` | 错误/不可用 `#ef4444` |
